I build software for multilingual document retrieval, distributed storage, and on-chain applications.

## Selected projects

### [Medical Guideline Chatbot](https://medibot.leira.com.vn/)

Contributed to a lab chatbot for querying medical guidelines. The system extracts text from PDFs with OCR when needed, retrieves and reranks relevant passages, and streams answers based on those passages.

`FastAPI` · `LangGraph` · `PostgreSQL` · `pgvector`

### [Markdown RAG Pipeline](https://github.com/NQKhaixyz/RAG)

Built a retrieval-augmented generation pipeline that splits Markdown by section, finds passages with multilingual embeddings, and uses maximal marginal relevance (MMR) to reduce redundancy before generating an answer with Gemini.

`Python` · `NumPy` · `Hugging Face` · `Gemini`

### [MerkleKV](https://github.com/AI-Decenter/MerkleKV) & [MerkleKV Mobile](https://github.com/NQKhaixyz/MerkleKV-Mobile)

Implemented [Java and Rust client libraries](https://github.com/AI-Decenter/MerkleKV/pull/59) for a distributed key-value store that replicates updates over MQTT and uses Merkle trees to detect divergence. Worked on Windows packaging for the Flutter demo.

`Rust` · `Java` · `Flutter` · `MQTT`

### [ChocoChoco](https://github.com/NQKhaixyz/chocochoco)

Built a Solana game where the side with fewer players wins the round. A commit–reveal protocol keeps each player's choice hidden until the reveal phase.

`Solana` · `Anchor` · `React` · `TypeScript`

### [VIDDHANA Miner](https://github.com/NQKhaixyz/Viddhana)

Built a dashboard for a platform that rewards network connectivity and uptime. It shows live earnings, network statistics, and countdowns to the next reward period.

`Node.js` · `Express` · `React` · `PostgreSQL`
